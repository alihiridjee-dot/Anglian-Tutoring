# Practice content fixes — 6 Oct 2026

The AI-written practice library (every generated quiz and task, origin `generated`) was reviewed in full and
corrected in production. `2026-10-06.json` beside this file is the record: for each fix, the row, the problem,
and the exact `before` and `after` values of the fields that changed.

## What was fixed

142 fixes (3 critical, 46 major, 93 minor): 95 quiz questions (`mcq_questions`) and 47 task questions
(`homework_questions`), out of 176 quiz and 140 task questions. Clean questions were not touched.

- **Critical:** a published wrong answer key (EDEX 3.11B Q7); a stem calling C₆₀ a giant structure (EDEX 1.38);
  iron + sulfur built to give Fe₂S₃ instead of FeS (EDEX 1.53).
- **Major:** wrong science (×5000 with a light microscope, solid non-metals "don't conduct", 7.3 g of
  hydrochloric acid treated as 7.3 g of HCl, bacteria reproducing sexually); questions with a second defensible
  answer; stems that gave the answer away; A-level terms; repeated questions; mark schemes that contradicted
  themselves, credited misconceptions (the cornea for a cataract, plasmids in every prokaryote, iron(III)
  chloride, graphite "melting between its layers") or referred to an answer line students don't have; a task
  copied from a 2024 Edexcel paper, rewritten as iron and iodine.
- **Minor:** answer keys much longer than the other options, explanations naming options by letter, notation
  (Mᵣ, Aᵣ), garbled examples, missing common correct answers.

After: every quiz and task passes the app's checks (`validateQuestions`); the answer is the strictly longest
option in 10% of questions (was 41%; chance is 25%) and at least 1.4× every other option in 1% (was 20%).

## How

Three reviewers drafted fixes against one rubric; a separate verifier per batch checked each one (all
calculations redone, every distractor argued for) and accepted, revised or rejected it (none rejected, 18
revised). Each fix was applied only if the live row still held exactly its `before` values, then read back.
Quizzes students had already attempted (EDEX 0.1, 1.1, 1.38) kept their answer keys and option order: wording
changed only. No task with a submission had its marks or prompt changed.

## Reverting one fix

Set the row's fields back to `before`, guarded on `after` so a later edit isn't overwritten. Entries fixed by
hand carry an `id_prefix` and, where only sentences changed, `replaced` pairs of `[before, after]` text.

```sql
update public.mcq_questions set correct_index = 3, explanation = '…before…'
 where id = '…' and correct_index = 1 and explanation = '…after…';
```
